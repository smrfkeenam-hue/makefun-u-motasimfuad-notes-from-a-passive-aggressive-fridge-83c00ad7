A smart fridge's passive-aggressive door-screen note for its owner: a smug door-alarm log, a petty 3 a.m. grudge, and the yogurt as witness.

## Run it

```sh
python3 main.py
```

The note is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
